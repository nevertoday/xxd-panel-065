# 🦁 XXD Panel 065

### 검정색 구조선과 두 개의 소스 이미지 색상 선을 사용하여 손으로 그린 색상 리듬 만들기

<a href="README.md">简体中文</a> · <a href="README.en.md">English</a> · <a href="README.ja.md">日本語</a> · <a href="README.ko.md">한국어</a> · <a href="README.ar.md">العربية</a>

Panel 065는 손으로 그린 가늘고 간헐적으로 보정 흔적이 있는 검은색 선을 뼈대로 사용한 다음 사진에서 두 가지 긴장된 강조 색상을 선택하여 컬러 선과 검은색 선을 약간 어긋나거나 겹치거나 평행하게 만듭니다.

**키워드:** 검정색 구조선 · 2색 강조선 · 손으로 칠한 색상 등록 · 오래된 인쇄 위치 변경 · 미세 조판

## 사용

```text
/xxd-panel-065 photo.jpg --mode design-only --size 3:4 --text prompt --locale ko-KR
```

단일 이미지, 디렉터리 배치, 4가지 출력 모드, 다양한 크기 및 3가지 텍스트 모드를 지원합니다. 전체 동작은 [SKILL.md](SKILL.md)를 참조하세요.
