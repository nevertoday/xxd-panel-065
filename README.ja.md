# 🦁 XXD Panel 065

### 黒の構造線と 2 つのソース画像の色の線を使用して、手描きの色のリズムを作成します

<a href="README.md">简体中文</a> · <a href="README.en.md">English</a> · <a href="README.ja.md">日本語</a> · <a href="README.ko.md">한국어</a> · <a href="README.ar.md">العربية</a>

Panel 065は、修正跡のある細く断続的な黒い手描きの線を骨格として、写真の中から緊張感のあるアクセントカラーを2色選び、色の線と黒い線を微妙にずらしたり、重ねたり、平行させたりしています。

**キーワード:** 黒の構造線・2色のアクセント線・手描きの色登録・古い印刷のずれ・マイクロ植字

## 使用する

```text
/xxd-panel-065 photo.jpg --mode design-only --size 3:4 --text prompt --locale ja-JP
```

単一画像、ディレクトリ バッチ、4 つの出力モード、複数のサイズ、および 3 つのテキスト モードをサポートします。完全な動作については、[SKILL.md](SKILL.md) を参照してください。
